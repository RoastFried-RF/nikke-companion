작업 ID: P-025
제목: 크롬 확장으로 계정 받기: 이미 로그인된 브라우저의 세션을 한 번의 클릭으로
설명: 사용자 결정(2026-11-12): 계정 받기는 **이미 로그인돼 있는 크롬**을 써야 한다 — 자동 로그인(SSO)으로 쓰는 사용자는 비밀번호를 모르므로 앱 안의 로그인 창(P-022)에서는 로그인할 수 없다. 작은 크롬 확장(Manifest V3, 저장소의 extension/ 폴더 — 개발자 모드의 "압축해제된 확장 프로그램을 로드합니다"로 설치)을 만든다: blablalink에 로그인된 상태에서 확장 아이콘의 단추를 누르면 확장이 blablalink API 요청에 실릴 쿠키를 읽어 이 PC에서 돌고 있는 오버레이에 넘기고, 오버레이는 P-022의 흐름(쿠키 저장 → 수집 → 변환 → 저장)을 이어서 돌린다. 크롬의 쿠키 저장소 파일을 앱이 직접 읽는 방식은 쓰지 않는다. **보안 규칙은 P-022와 같다**: 쿠키는 엔진의 scraper/.session_cookie 한 곳에만 쓰고, 화면·로그·오류·응답·이벤트에 내보내지 않는다. 확장은 쿠키를 이 PC의 오버레이(127.0.0.1) 말고는 어디에도 보내지 않고 저장하지도 않는다. **너(에이전트)는 실제 쿠키·프로필·계정 파일을 읽지 말고, 사용자의 크롬에 확장을 설치하거나 실제 blablalink에 로그인하지 마라** — 가짜 값과 가짜 요청으로만 개발·테스트한다.

수락 조건:
- 확장(extension/): 권한은 cookies와 호스트 권한 두 가지(blablalink 도메인, 127.0.0.1)뿐이다. 다른 사이트의 쿠키·탭 내용·방문 기록에 닿는 권한이 없다 — manifest를 읽는 테스트로 확인한다. 팝업 하나(단추 "오버레이로 보내기", 상태 한 줄, 연결 코드 입력 칸)이고 백그라운드에서 스스로 돌지 않는다(단추를 눌렀을 때만 쿠키를 읽는다)
- 확장이 보내는 것: api.blablalink.com 요청에 실릴 쿠키로 만든 Cookie 헤더 한 줄. game_token·game_openid가 없으면 보내지 않고 "blablalink에 로그인돼 있지 않다"고 알린다. 쿠키 목록 → 헤더 한 줄을 만드는 부분은 순수 모듈로 두고 node --test로 단위 테스트한다(도메인이 맞는 것만, 필수 쿠키 확인)
- 오버레이의 수신: 127.0.0.1에만 묶인 작은 수신부. 계정 화면에서 "크롬 확장 연결"을 켰을 때만 열리고(기본 꺼짐, 상태를 기억), 끄거나 앱이 끝나면 닫힌다. 다른 PC에서 닿을 수 없다(루프백에만 묶임 — 테스트로 확인)
- 연결 코드: 오버레이가 만든 무작위 코드를 계정 화면에 보여 주고, 사용자가 확장에 한 번 입력한다. 수신부는 코드가 맞는 요청만 받는다(틀리면 거부하고 여러 번 틀리면 잠시 막는다). 코드를 다시 만드는 단추가 있다. 코드는 쿠키가 아니라 화면에 보여도 된다
- 수신부는 정해진 요청 하나만 받는다: 방법·경로·형식·크기 제한이 있고 그 밖은 거부한다. 응답과 로그에 쿠키가 담기지 않는다(성공·실패와 사유만). 웹 페이지가 이 수신부를 부르지 못하게 한다(브라우저의 다른 출처 요청에 허용 헤더를 주지 않고, 확장이 아닌 출처는 거부) — 각각 테스트한다
- 받은 뒤: P-022와 같은 정리·검사(normalize)를 거쳐 저장하고, "계정 새로 받기" 흐름을 자동으로 이어서 돌린다(수집 → 변환 → 저장 → 다른 화면의 계정 칸). 진행과 결과가 계정 화면에 보이고, 확장 팝업에는 "오버레이가 받았다 / 오버레이가 꺼져 있다 / 코드가 틀리다 / 로그인돼 있지 않다"가 구분돼 보인다
- 쿠키 비노출 테스트를 이 경로에도 둔다: 가짜 쿠키가 수신부의 응답·오류·로그·이벤트·명령 반환값에 나타나지 않는다
- 계정 화면의 순서: 1 크롬 확장(권장) 2 쿠키 붙여넣기 3 앱 안의 로그인 창(비밀번호로 로그인하는 사용자용). 처음 쓰는 사람이 따라 할 수 있게 확장 설치 순서를 화면에 적는다
- 새 의존성은 꼭 필요한 작은 것만 쓰고 이유를 적는다(수신부는 표준 라이브러리로도 가능하다). capability에는 새 명령만 더한다
- 문서: app/README.md §크롬 확장으로 계정 받기(설치·연결·보안·한계 — 크로뮴 계열 브라우저, 확장을 고치면 다시 로드), extension/README.md, 루트 CLAUDE.md. 기존 테스트가 계속 통과하고 cargo clippy --all-targets에 경고가 없다
