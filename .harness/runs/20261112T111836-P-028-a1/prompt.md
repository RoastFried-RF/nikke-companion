작업 ID: P-028
제목: UI 개편 3: 오버레이 위젯 — 보스 한 줄 카드, 접힌 모드, 자동 표시
설명: 먼저 docs/ui-redesign.md를 읽어라. **이 작업**은 게임 위에 뜨는 오버레이 창을 작은 위젯으로 바꾼다. 오버레이는 결과만 보여 준다 — 계산·계정 연결·설정은 데스크톱 앱 창(P-027)에서 한다. 시안: 한 줄 카드(보스 이미지 44px 안팎, 보스 이름, "약점 ○○", 총딜, 작은 초상화 5장 — 버스트 배지와 약점 속성 강조 테두리), 접으면 보스 이미지·이름·총딜만 있는 알약. 게임은 읽기만 한다. P-021(자동 추적)·P-024(게임 위에 머물기)의 동작은 유지한다.

수락 조건:
- 세 가지 모양: 접힘(알약 — 보스 이미지·이름·총딜), 한 줄 카드(기본 — 위 시안), 펼침(한 줄 카드 + 한 줄 요약 + 2·3위 + 자리 순서 안내). 누르거나 단축키로 오간다. 창 크기가 모양에 맞게 줄고 늘어난다(빈 투명 영역이 게임 클릭을 가로막지 않는다)
- 자동 표시: 자동 추적이 이상 개체 화면과 보스를 인식하면 그 보스의 카드가 보인다. 이상 개체 화면이 아니게 되면 잠시 뒤(설정값) 접히거나 숨는다 — 사용자가 핀으로 고정하면 그대로 둔다. 인식이 unknown인 동안에는 바꾸지 않는다. 규칙은 순수 함수로 두고 단위 테스트한다
- 오버레이는 계산을 시작하지 않는다. 결과가 없거나(계정 없음·아직 계산 안 함) 계산 중이면 한 줄로 알리고 "앱 열기"(앱 창을 앞으로 가져온다)만 둔다. 계산 중이면 진행을 작게 보인다
- 보이는 것은 데스크톱 앱이 저장한 마지막 결과다(P-027의 공유 바탕). 앱이 새로 계산하면 오버레이가 바뀐다. 결과가 어느 계정·언제 것인지 작게 보이고, "추정" 표시는 항상 있다. 미확인 값·속성 상성 미반영 같은 표시는 펼침 모양에서 보인다
- 위치: 끌어서 옮길 수 있고 자리를 기억한다. 게임 창에 붙이기를 켜면 게임 창 기준의 자리를 기억해 따라간다(P-024의 가장자리 처리 유지). 화면 밖으로 나가면 안쪽으로 되돌린다. 자리 초기화가 설정에 있다
- 오버레이 설정(앱 창의 설정 화면): 크기 배율, 불투명도(정보 영역은 기본 불투명), 자동 숨김 시간, 기본 모양, 클릭 통과. 단축키(보이기/숨기기·클릭 통과·모양 바꾸기)는 오버레이에 작게 안내된다
- 오버레이 창의 권한은 필요한 것만이다(결과·상태 읽기, 창 조작, 추적 상태, 이미지). 계정·엔진 실행·파일 저장 명령은 오버레이 창에서 부를 수 없다 — 계약 테스트
- 컴포넌트 테스트: 세 모양, 결과 없음·계산 중·오류, 보스가 바뀔 때, 긴 이름, 이미지 없음. 기존 자동 추적·게임 위에 머물기 테스트는 계속 통과한다. cargo clippy --all-targets 경고 없음. app/README.md·docs/ui-redesign.md 갱신
