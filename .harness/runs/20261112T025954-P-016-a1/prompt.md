작업 ID: P-016
제목: 오버레이 다듬기: 계산 중단, 포커스 유지, 파일 고르기 창
설명: (1) 계산 중단: 추천·비교가 도는 동안 중단 단추로 멈춘다 — Rust가 엔진 프로세스를 끝내고 화면은 '중단됨'을 보인다. (2) Alt+Shift+O로 오버레이를 다시 보일 때 창이 활성화돼 게임의 키보드 포커스를 가져가지 않게 한다(Win32로 활성화 없이 보이기). 클릭 통과 전환도 포커스를 바꾸지 않아야 한다. (3) 파일 고르기 창이 항상 위인 오버레이 뒤에 가려지지 않게 한다(대화 상자의 부모를 오버레이 창으로). 게임 창은 건드리지 않는다.

수락 조건:
- 중단: engine_run_batch가 도는 중에 중단 명령을 부르면 모든 엔진 프로세스가 끝나고 호출이 '중단됨' 오류로 돌아온다. 실제 엔진을 쓰는 Rust 테스트가 있다: 긴 배치를 시작하고 중단한 뒤 수 초 안에 돌아오고 남은 python 프로세스가 없다
- 중단 뒤 다시 실행할 수 있다. 화면 테스트(가짜 런타임): 실행 중에만 중단 단추가 보이고, 중단되면 상태가 '중단됨'이며 이전 결과는 그대로 남는다
- 활성화 없이 보이기: 상태 전환 규칙에 '보일 때 활성화하지 않는다'가 드러나고(단위 테스트), 창에 반영하는 코드는 Win32의 활성화 없는 표시를 쓴다. Windows가 아니면 기존 동작
- 파일 고르기 창은 오버레이 창을 부모로 연다
- 기존 테스트가 계속 통과한다. app/README.md를 갱신한다

하네스가 네가 끝난 뒤 직접 실행할 검증 명령 (네가 미리 돌려 봐도 된다):
