작업 ID: P-029
제목: 요격전 계획: 장비 현황과 보스 보상 연결, 오늘 돌 보스 추천, 요격전 기록
설명: 먼저 docs/ui-redesign.md와 docs/intercept.md를 읽어라. 커뮤니티 도구 모음(니케 마이너 갤러리 "니케 유용한 툴 모음집")에서 일반 사용자가 실제로 쓰는 기능을 참고해, 이 앱의 요격전 흐름에 맞는 것을 넣는다(2026-11-12 사용자 요청: "기능은 그 도구들을 참고"). 대화형 세션이 직접 열어 본 것: **니케 장비 현황**(계정 동기화 → 니케별 머리·몸통·장갑·다리 기업장비 현황 표, "기업장비 필요 현황", "장비파밍 예상일자", 기업·클래스 거르기, 유효/미사용 표시), **레츠도로**(지금 진행 중인 콘텐츠의 보스·속성·기간 카드, 솔레/유레 덱, 버프 계산기, 마이페이지의 기록관·즐겨찾기), **Enikk**(플레이어 육성 비교 — 속성별 커버리지), 모듈 기록 시트(요격전 보상 기록). 그 사이트들의 코드·이미지·데이터를 가져오지 않는다 — 기능의 아이디어만 참고한다. 이 앱이 이미 가진 것: 계정 프로필에 니케별 4부위 장비(등급·기업·강화)와 오버로드 옵션이 있고(src/core/import-profile.mjs, docs/data-model.md), 이상 개체 보스마다 보상 부위가 확인돼 있다(인디빌리아 몸통·울트라 머리·하베스터 다리·미러 컨테이너 팔·크라켄 커스텀 모듈 — data/intercept/anomaly.json). 이 둘을 이으면 "오늘 어느 보스를 돌아야 하는가"에 답할 수 있다. 계산은 src/core의 순수 모듈로 만들고(node: import 금지) 화면은 P-026의 부품으로 그린다.

수락 조건:
- 장비 현황(순수 함수 + 화면 "내 니케"의 한 구획): 니케별 4부위의 상태(미장착 / 일반 등급 / 기업 장비 / 오버로드 — 계정 상태에 있는 값 그대로)를 초상화 옆 네 칸으로 보인다. 부위별·기업별로 "오버로드가 아닌 칸이 몇 개인지" 요약한다. 계정 상태에 없는 정보(예: 인벤토리에 가진 장비 수)는 지어내지 않는다 — 없으면 없다고 적는다
- 어느 니케의 장비가 중요한지: 요격전 추천 결과의 1위 편성(보스 5종)에 든 니케를 "주력"으로 본다(결과가 없으면 사용자가 즐겨찾기로 고른 니케, 그것도 없으면 육성 점수 상위). 기준은 화면에 한 줄로 적는다
- 오늘 돌 보스 추천: 주력 니케의 비어 있거나 낮은 장비 부위를 보스의 보상 부위와 이어 "머리 장비가 가장 급하다 → 울트라"처럼 한 문장과 보스별 필요 칸 수 막대로 보인다. 근거(어느 니케의 어느 부위)가 펼쳐 보인다. 보상 확률·획득 수는 모르므로 "언제 다 모이는지" 같은 예상은 하지 않고, 모른다는 사실을 적는다
- 요격전 기록: 사용자가 보스별로 실제 대미지(모의전 또는 실전)와 날짜·달성 단계를 손으로 적어 둘 수 있다(앱 창에서 입력, 계정 폴더에 저장 — gitignore). 같은 보스의 추정 총딜과 나란히 보이고 차이(비율)가 표시된다. 기록이 있으면 요격전 화면의 "추정 · 실전 미대조" 배지가 "기록과 ○○% 차이"로 바뀐다 — 추정치를 기록에 맞춰 고쳐 쓰지는 않는다(보정은 이 작업이 아니다)
- 홈의 "오늘의 요격전" 카드: 오늘 돌 보스 추천 한 줄 + 그 보스의 1위 편성 초상화 5장 + 지난 기록. 누르면 요격전 화면의 그 보스로 간다
- 속성 커버리지: 속성 5종마다 "키운 딜러"가 몇 명인지 막대로 보인다(기준 — 예: 스킬·돌파가 일정 이상 — 을 화면과 문서에 적고 순수 함수로 테스트한다). 어느 보스(약점 속성)가 약한지 한눈에 보인다
- 단위 테스트(순수 함수): 장비 상태 분류, 주력 선정의 세 경우, 보스 추천과 동률 처리, 기록과 추정의 비교, 커버리지 기준. 화면 테스트(가짜 backend): 장비 칸·추천 문장·기록 입력과 복원·배지 변화. 시험 데이터는 data/samples/account.large.sample.json을 쓴다(실제 계정 파일을 읽지 않는다)
- 문서: docs/data-model.md(요격전 기록 형식), docs/ui-redesign.md(새 화면 구획), app/README.md. 기존 테스트가 계속 통과하고 cargo clippy --all-targets에 경고가 없다
